## Fault contract

Agreed with filesystem owner: constructor `SessionEngine(storeURL:fault:)`, where fault is an optional throwing `@Sendable (String) -> Void`.

The authored tests use `create.afterBaseline`; `apply.afterJournal`, `apply.beforeMutation`, `apply.afterMutation`, `apply.beforeVerified`, `apply.afterVerified`, `apply.beforeCommit`; corresponding six `undo.*` hooks; `recover.beforeMutation`, `recover.afterMutation`. Hooks fire for each selected file where applicable. Apply interruption should recover original source bytes and Editing state. Undo interruption should recover the applied revision. Recovery refuses current bytes that match neither expected prestate nor poststate. Repeating completed recovery succeeds without further changes.

Additional offered hooks `create.beforeCapture`, `create.afterDraft`, `review.beforeSeal`, `review.afterSeal` are not yet exercised in this independent suite. The filesystem owner may have separate unit coverage; do not merge counts or report those as this suite's results.
